The snake image is currently blank because the workflow that generates it hasn't been added yet. Here's how to turn it on:

**Step 1 — Create your profile repo (skip if you already have one)**
Create a new GitHub repo named **exactly** your username: `M-Shaheer-Khan`. This is the special "profile README" repo — GitHub auto-detects it and shows its README on your profile page. Push this README.md file into it as `README.md`.

**Step 2 — Add the workflow file**
Inside that same repo, create the file `.github/workflows/snake.yml` with this content:

```yaml
name: Generate Snake Animation

on:
  schedule:
    - cron: "0 0 * * *"   # runs once a day
  workflow_dispatch:        # lets you trigger it manually too
  push:
    branches:
      - main

jobs:
  generate:
    permissions:
      contents: write
    runs-on: ubuntu-latest
    steps:
      - name: Generate snake animation
        uses: Platane/snk@v3
        with:
          github_user_name: M-Shaheer-Khan
          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark

      - name: Push snake animation to output branch
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

**Step 3 — Enable workflow permissions**
Go to your repo → **Settings → Actions → General → Workflow permissions**, and set it to **"Read and write permissions."** This lets the Action push the generated SVG to a new `output` branch.

**Step 4 — Run it**
Go to the **Actions** tab in your repo → select "Generate Snake Animation" → click **Run workflow** to trigger it manually the first time. It will then also run automatically every day after that.

**Step 5 — Confirm it worked**
After the run finishes, check that a new branch called `output` was created in your repo, containing `github-snake.svg` and `github-snake-dark.svg`. Once that branch exists, the snake in this README will render automatically — no further changes needed.
